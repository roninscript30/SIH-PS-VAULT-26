# 🧭 How to Use This Vault

## Getting Started
1. Open `HOME.md` as your entry point
2. Install the **Dataview** plugin for dynamic queries
3. Use **Graph View** to explore connections

## Finding Problems
- **By theme**: `02-Themes/` or [[_Theme-Index]]
- **By organization**: `03-Organizations/` or [[_Organization-Index]]
- **By technology**: `04-Technologies/` or [[_Technology-Index]]
- **By domain**: `05-Domains/` or [[_Domain-Index]]
- **All problems**: [[All-Problems-Master-Table]]

## Strategic Analysis

## Tips
- Use `Ctrl+O` to quick-open any note by name
- Use `Ctrl+Shift+F` to search across all vault content
- Click any link to navigate; use backlinks to see what links TO a page
- Graph view (`Ctrl+G`) shows the full knowledge network
